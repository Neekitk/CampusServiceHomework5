# ADR 0009: Переход от Status к StatusCode

**Статус:** Принято

## Контекст

В модуле «Заказ справок (Деканат)» состояние заявки ранее хранилось
в строковом поле `Status`.

Для задачи `CAMPUS-107` необходимо перейти к числовому представлению
состояния через поле `StatusCode`.

Прямое удаление старого поля может привести к ошибкам в работающих
версиях приложения, поэтому требуется выполнить изменение без остановки
системы.

## Решение

Использовать паттерн Expand and Contract.

На фазе Expand в таблицу добавляется новое поле `StatusCode`, при этом
старое поле `Status` сохраняется.

В переходный период приложение записывает состояние одновременно в
`Status` и `StatusCode`.

На фазе Migrate существующие значения `Status` преобразуются в числовые
коды и записываются в `StatusCode`.

После перехода всех компонентов системы на новое поле выполняется фаза
Contract и поле `Status` удаляется.

## Последствия

Преимущества:

- Миграция выполняется без остановки сервиса;
- Сохраняется обратная совместимость во время перехода;
- Уменьшается риск потери исторических данных;
- Новые компоненты могут использовать числовые значения статусов.

Недостатки:

- В переходный период необходимо поддерживать два поля;
- Требуется дополнительная логика одновременной записи;
- Удаление старого поля возможно только после проверки всех клиентов.
